# PlanRmode installers

Download the installer from the [latest release](https://github.com/Arnolddc04/PlanRmode-releases/releases/latest):

- Windows: `PlanRmode-Setup-<version>.exe`
- Linux: `PlanRmode-Setup-<version>-linux-x64.sh` (run it with `sh`)

The app checks this repo for new versions and updates itself.
